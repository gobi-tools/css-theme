    • Any element can be turned into a carousel by adding the aria-roledescription="carousel" attribute, as recommended by the W3C.

    Ordered or unordered lists are preffered, because they work without specifying the additional aria-roledescription="slide" attribute on each individual slide.

    The aria-label attribute can be used to give information about the contents of the carousel.

    Carousel slides can, in fact, hold all sorts of complex components. More interestingly, they can be combined with grids to produce a variety of layouts.

    If you choose a column size that divides the available space neatly into equal parts, you can place a number of preview slides on the viewport, whilst keeping the rest hidden.

    ClassOutcome
    colAll slides will be visible
    col-1The first 12 slides will be visible
    col-2The first 6 slides will be visible
    col-3The first 4 slides will be visible
    col-4The first 3 slides will be visible
    col-5The first 2 slides will be visible

    If you choose a column size that does not divide the avaibale space neatly, you can generate a preview of the next slides.

    Below is an example using col-11, which will mean most on large displays the first slide will be fully visible whilst the second will peek from the right.

    A choise of col-5 will allow two slides to be fully visible and a third to peek, whilst choices like col-7, col-8, etc will allow more or less of the second slide to peek through.

    Note on smaller devices carousels are responsive, so only one slide will be visible.
