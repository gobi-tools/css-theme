    • You can add a loading indicator to an element by adding the aria-busy attribute, with truefalse.

    For example, it can be applied to buttons (with or without exiting icons):

    <!-- icon button -->
<button aria-busy>
  <svg ...></svg>
</button>
          
<!-- text button -->
<button aria-busy>
  Button
</button>

<!-- left side icon -->
<button aria-busy>
  <svg ...></svg>
  <span>Home</span> 
</button>

<!-- right side icon -->
<button type="reset" aria-busy>
  <span>Play</span>
  <svg ...></svg>
</button>

    It can be applied to paragraphs or other text elements:

    Loading...

    Click me

    <p aria-busy>Loading...</p>
          
<a href="..." aria-busy>Click me</a>

    Or it can be applied to block elements. In this case the whole content is hidden when loading.

    PressCtrl + Qto quit

    <blockquote aria-busy>
  <p>
    Press 
    <kbd>Ctrl + Q</kbd>
    to quit
  </p>
</blockquote>

    And cards of different types, where the loading spinner is also horizontally centered.

</article>
